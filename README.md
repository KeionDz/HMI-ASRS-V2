# HMI-ASRS-V2

HMI application for an automated storage and retrieval system.

## Tech Stack

- Frontend: React, TypeScript, Vite
- Backend: Node.js, TypeScript, Express
- Database: PostgreSQL
- Docker Compose

## Run Frontend

```powershell
cd frontend
npm install
npm run dev
```

## Run Backend

```powershell
cd backend
npm install
npm run dev
```
